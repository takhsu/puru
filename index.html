Copy it when you need it. Save it when it's worth keeping.

Screenshots shouldn't pile up into a mountain on your computer. If you only need an image for a moment, copy it and skip saving. Only the ones worth keeping go into the screenshot manager. puru CUT makes both as easy as two quick actions.

Capture, mark up, send

  1. Press the capture hotkey, drag to frame the area, release the left button.
  2. Click the notification at the bottom right to mark it up: arrows, boxes, text, speech bubbles, blur.
  3. Press Save, then paste it into LINE or an email.

Both buttons.
Copy only.

Left plus right button: copy only.

While you are framing, keep the left button down and click the right one. The image goes to the clipboard only: nothing is saved and no window opens. Paste it straight into ChatGPT, Claude, Gemini or a LINE chat.

puru CUT setup instructions

  1. Download PURUCUT-0.9.0-portable-x64.zip.
  2. Right-click the zip, choose Extract All, and extract it to a folder you like (for example, D:\puru CUT). Do not run it directly inside the zip.
  3. Open the extracted PURUCUT folder and double-click PURUCUT.exe. Follow the simple setup shown on the first launch.
  4. If Windows displays “Windows protected your PC”, click More info, then Run anyway. This happens because I haven't purchased a code-signing certificate, not because there is a problem with the app.

A few reminders:

  • No installation needed. All data stays in the PURUCUT folder; move the whole folder to take it with you.
  • To remove it, simply delete the whole folder.
  • Requires Windows 10 or 11 (64-bit).
  • If you run into any problems, please report them directly to me.
